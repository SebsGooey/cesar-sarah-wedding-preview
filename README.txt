Live: https://sebsgooey.github.io/cesar-sarah-wedding-preview/

English/Spanish invitation, optional music, automatic photo slideshow, mobile and desktop layouts, accurate calendar download, and a real RSVP form. Photos are from the couple’s Zola wedding website; see PHOTO-SOURCES.json. Music remains a placeholder.

RSVP responses are stored in a private D1 database through the Sites service configured in config.js. Guests need no account. The hosts sign into the private guest list using their shared username and password, and can download a CSV for Google Sheets or Excel. The shared Google Sheet does not sync automatically. Repeat submissions on the same browser update the existing response. Clearing browser storage loses the update token.

The song suggestion form is still a clearly labeled local-only preview.

Edit event details in config.js and bilingual copy in i18n.js. There is no invented end time, dress code, or RSVP deadline. To preview: python3 -m http.server 4173. GitHub Pages publishes the main branch at the repository root.
